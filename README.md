**PINN – Viga de Euler-Bernoulli Biapoiada**

- Equação governante: EI * d⁴w/dx⁴ = q     (carga distribuída uniforme)

- Condições de contorno (apoios simples nas duas extremidades):
     w(0)  = 0   →  deslocamento nulo
     w(L)  = 0   →  deslocamento nulo
     w''(0)= 0   →  momento fletor nulo
     w''(L)= 0   →  momento fletor nulo
  
- Solução analítica exata:
       w(x) = (q / (24·EI)) · x · (L³ - 2·L·x² + x³)
